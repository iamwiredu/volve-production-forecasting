# Data

The Volve data is not stored in this repository. Download it from Equinor and accept the licence there:

1. Go to Equinor's Volve data page (https://www.equinor.com/energy/volve-data-sharing) and follow the link to the data download.
2. Download the production data file, **Volve production data.xlsx**.
3. Put it in this folder as `data/Volve production data.xlsx`.

The data is released by Equinor under the Equinor Open Data Licence.
